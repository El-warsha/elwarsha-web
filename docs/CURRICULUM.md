# Eight-week progression

The frontend and backend repositories share one weekly concept.

1. Architecture and modularity
2. State and data modeling
3. Asynchronous data flow
4. Authentication and authorization
5. Validation and reliability
6. Testing
7. Performance
8. Delivery

Week 1's qualifying slice is the program gist. The task feature is
`src/features/tasks` (`useTasks`, route `portal/assignments`). Labels are not
in the UI yet.

Use the generated API client. Do not add a second approval system in the portal.
